# Integration Boundaries
GitHub is authoritative for source, migrations, policy and evidence. Cloudflare Worker accesses D1/R2 through native bindings. ChatGPT is the interactive reasoning surface; backend deterministic jobs do not call paid inference APIs.

Supabase, n8n and Railway are legacy systems and remain untouched. No dual writes, migration, credential rotation, workflow activation or decommissioning is permitted.

Android and desktop access use the same responsive HTTPS Worker interface. Until a client is implemented and tested on both platforms, access is NOT VERIFIED; a documented API contract is not proof of device compatibility.
