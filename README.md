# ECC ORBIT — Archival Transfer Package

Prepared: 2026-11-11. This package is designed to let a new GPT user continue without access to the originating conversation. It contains project notes, the available conversation record in summarized form, status, privacy controls, and a continuation prompt. It does **not** contain the source audio.

## Start here
1. Read `01_PROJECT_BRIEF.md` for the purpose, scope, and requirements.
2. Read `02_CONVERSATION_CONTEXT.md` for user-provided facts and prior assistant decisions.
3. Read `03_STATUS_AND_NEXT_STEPS.md` before continuing Phase 1.
4. Read `04_PRIVACY_AND_CONSENT.md` before handling any audio or excerpts.
5. Use `05_PORTABLE_CONTINUATION_PROMPT.txt` to start a new GPT session.

## Source and evidence labels
- **User-provided / source-derived** means explicitly stated by the user or visible in the bounded referenced conversation.
- **Prior assistant report** means a finding asserted in the conversation, not independently re-created during this handoff.
- **Re-verified here** means checked against a file available in this transfer session.
- **Inference / proposal** means a recommendation, not an established fact.
- **Unknown / unverified** means evidence is insufficient.

The only source files in this local project mirror were `Audio_Project_Checklist_Template.docx` and project instructions; `sources/` contains no files. The conversation shows an original `pod worthy.aac` attachment, and that attachment remains available at a temporary local preview path in this session. The attachment is omitted from this package because one participant did not know the conversation was being recorded and no informed transfer/publication permission is documented. The audio must be transferred separately only after a deliberate privacy and consent review. Do not assume the temporary path will persist.
